# EverwellStudioCapstone

Rachel Hanslik CSC450 CS Capstone - Everwell Studio Website and Membership Management System
Project Overview:
Everwell Studio is a website for the wellness studio that offers massage services, head and scalp treatments and wellness products offered in store.
Customers can create accounts, view membership details and reward information and complete the electronic consent forms for services.
Employees and owner will have access to administrative dashboard able to manage customer accounts, memberships/rewards and consecnt forms.

Technologies:
-HTML
-CSS
-JavaScript
-Java
-MySQL
-JDBC
-Visual Studio Code
